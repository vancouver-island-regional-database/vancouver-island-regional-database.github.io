External Resources

A directory of government registries, open data portals, and independent research tools for citizen researchers looking to verify a claim, look up a public record, or dig into a topic using primary sources — in British Columbia and, where relevant, federally across Canada.

Government links change addresses and go dead more often than they should. Every entry below includes a backup search link scoped to that same website, so if the direct link breaks, you can search for where the page moved. Resources are also tagged for accessibility — see the key below — so you know what to expect before you click.

This database is in its early stages and this list is actively growing. Check back for updates.
