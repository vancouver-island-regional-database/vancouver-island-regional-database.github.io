External Resources

A curated set of official records, registries, and research tools for looking into a property, company, or public official mentioned in a document you found elsewhere on this site.

Every entry links directly to its primary source, with a plain-language note on what it's useful for, what it costs, and how hard it is to use. Government links change addresses and go dead more often than they should — every entry also includes a backup search link scoped to that same website, so if the direct link breaks, you can search for where the page moved.

This database is in its early stages and this list is actively growing. Check back for updates.
